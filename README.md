# VK Community Broadcaster

Асинхронно-ориентированный скрипт рассылки сообщений подписчикам сообщества ВКонтакте с учетом лимитов API VK.

---

## Описание проекта

**VK Community Broadcaster** — это инструмент для авторов и администраторов сообществ ВКонтакте, позволяющий организовывать массовую рассылку сообщений по списку участников группы напрямую через личные сообщения от имени сообщества.

Проект использует официально поддерживаемую библиотеку `vk_api` и механизмы LongPoll для безопасного и удобного взаимодействия с администратором.

---

## Ключевые возможности

* **Авторизация по ADMIN_ID**: Команды управления рассылкой доступны исключительно администратору, чей ID указан в конфигурации.
* **Пошаговый диалог**: Ввод текста рассылки происходит в формате интерактивного диалога (состояние ожидания текста).
* **Безопасная пагинация**: Автоматическое получение полного списка участников группы пакетами по 1000 пользователей с паузами для предотвращения блокировок со стороны VK API.
* **Соблюдение лимитов отправки**: Встроена задержка в 1.2 секунды между отправкой сообщений для предотвращения попадания под спам-фильтры ВКонтакте.
* **Валидация и отчетность**: Проверка длины сообщения (до 4096 символов) и детальный итоговый отчет о количестве успешно доставленных сообщений.

## Стек технологий

* **Язык программирования**: Python 3.8+
* **Библиотека VK API**: `vk_api` (модуль `VkBotLongPoll`)
* **Механизм получения событий**: VK Bot LongPoll API

## Требования и установка

### 1. Требования
* Установленный интерпретатор Python 3.8 или выше.
* Сообщество ВКонтакте с включенными сообщениями и созданными ключами доступа (токен группы).
* Включенный Bot LongPoll API в настройках сообщества (версия API 5.131+).

### 2. Установка зависимостей
Установите библиотеку `vk_api`:
```bash
pip install vk_api
Настройка скрипта
Перед запуском открывается файл main.py и заполняются ключевые переменные конфигурации:

Python
GROUP_ID = '123456789'    # ID вашего сообщества (число без знака минус)
GROUP_TOKEN = 'vk1.a...'  # Токен доступа сообщества
ADMIN_ID = '987654321'    # Ваш персональный ID ВКонтакте
Инструкция по использованию
Запустите скрипт через терминал:

Bash
python main.py
Откройте диалог с вашим сообществом ВКонтакте от имени администратора (ADMIN_ID).

Отправьте команду:

Plaintext
рассылка
Бот запросит текст сообщения. Отправьте текст, который должны получить все участники.

Бот выполнит выгрузку участников, запустит цикл отправки и по окончании пришлет финальный отчет с количеством успешных отправок.
